# Development Guide

Local development workflow for the FinSight backend.

## Quick start

```bash
# Lightweight profile (no Postgres, no RabbitMQ, in-memory adapters)
cd backend && mvn spring-boot:run

# Full stack
docker compose up -d --build
./scripts/quick-demo.sh
```

## Frontend development

The static TypeScript client and the typed API wrappers live
under `frontend/`. See
[`docs/frontend-typed-client.md`](frontend-typed-client.md) for the
full architecture, and [`docs/rfcs/RFC-002-openapi-typescript-codegen.md`](rfcs/RFC-002-openapi-typescript-codegen.md)
for the design.

```bash
cd frontend
npm ci                # install
npm run typecheck      # tsc --noEmit
npm test              # vitest run
npm run build         # produces dist/app.bundle.js
npm run api:generate   # regenerate schema.d.ts from /v3/api-docs
npm run dev            # vite dev server with proxy to localhost:8080
```

The `mvn package` build runs `npm ci && npm run build` automatically
via the `frontend-maven-plugin`, then copies `dist/app.bundle.js`
to `src/main/resources/static/app.bundle.js`. The lightweight
preview mode can skip this with `-Dskip.frontend.build=true`.

## Regenerating the OpenAPI schema

```bash
# Start the backend (any profile)
cd backend && mvn -DskipTests spring-boot:run &

# Regenerate the typed schema from /v3/api-docs
cd ../frontend && npm run api:generate

# Typecheck + test
npm run typecheck && npm test

# Commit the regenerated schema.d.ts
git add src/api/generated/schema.d.ts
git commit -m "chore(api): regenerate typed schema from /v3/api-docs"
```

CI runs the same on every push via the `api-lint` job: it fails
the build if the freshly generated file is not byte-identical to
the committed one.

## Adding a new backend endpoint

1. Add the controller method in
   `backend/src/main/java/com/finsight/api/*Controller.java` with
   the right `@RequestMapping` / `@GetMapping` / `@PostMapping`
   annotations.
2. Add the docstring + example response to `docs/api.md`.
3. Regenerate the typed schema (above).
4. Add a typed wrapper in `frontend/src/api/<module>.ts`.
5. Optionally, add a bridge method in
   `backend/src/main/resources/static/api-bridge.js`.
6. Add a vitest case for the new wrapper.

## Database migrations

Flyway lives in `backend/src/main/resources/db/migration/`. Naming
convention: `V<n>__<snake_case_description>.sql`. Spring Boot runs
migrations automatically on startup in the `postgres` profile.

The lightweight preview profile (default `mvn spring-boot:run`)
skips Flyway and uses the H2 in-memory adapter, which is why
schema changes should always be tested with `docker compose up`
before merging.

## Troubleshooting

- **`mvn spring-boot:run` fails on port 8080** — kill any previous
  Spring process: `lsof -ti:8080 | xargs kill -9`.
- **`frontend-maven-plugin` fails during `mvn package`** — verify
  Node 20+ is installed and `npm ci` succeeds in `frontend/`.
  Use `-Dskip.frontend.build=true` to skip until network is fixed.
- **OpenAPI regeneration fails with 404** — confirm the backend
  is running: `curl -fsS http://localhost:8080/v3/api-docs | jq .title`.
- **Vitest picks up the wrong fetch** — the test environment is
  set to `node` in `vite.config.ts`. jsdom's fetch polyfill is
  intentionally bypassed so `vi.stubGlobal('fetch', ...)` actually
  replaces the implementation.

## Code layout

```
backend/src/main/java/com/finsight/
  api/             Spring @RestControllers + filters
  application/     Workflow orchestration and use cases
  domain/          Plain records (Company, Quote, etc.) + repository interfaces
  infrastructure/  Jdbc repos + SandboxClassLoader + migrations
  market/          Vendor clients (Eastmoney / Sina) + cache
  rag/             Hybrid RAG pipeline
  workflow/        Event-sourced workflow + Redis leases
```

```
backend/src/main/resources/
  application.yml
  static/             Static HTML / CSS / JS for the SPA
    app.js            The legacy IIFE
    dom.js            Shared DOM helpers (RFC 005)
    api-bridge.js     IIFE → typed-client bridge (RFC 002)
  templates/          (RFC 004 — Markdown report templates)
  db/migration/       Flyway SQL migrations
```

```
frontend/src/
  api/
    index.ts         createApiClient, ApiError, once()
    auth.ts          typed auth wrappers
    research.ts      typed research wrappers
    watchlist.ts     typed watchlist wrappers
    market.ts        typed market wrappers (history, recommendations)
    intelligence.ts  typed intelligence + document-index wrappers
    companies.ts     typed companies + password-reset wrappers
    workflow.ts      typed research-task wrappers
    generated/       openapi-typescript output (regenerated by api-lint)
  main.ts            entry point; sets window.finsight.api
```

# Visual foundations

## Direction

White-gold financial research surface: warm pearl layers, charcoal typography,
restrained champagne accents, and a softly iridescent translucent navigation rail.

## Cards and borders

- Most groups use separators rather than floating cards.
- Use cards only for distinct tasks: search, report brief, evidence source.
- Radius is 6–10px. Avoid pill-shaped containers except compact statuses.
- Shadows appear only on overlays and the primary search surface.

## Data

- IBM Plex Mono for prices, symbols, dates, versions, scores, and hashes.
- Positive and negative values always include `+`/`−`; color is secondary.
- Charts use one close-price series and restrained horizontal grid lines. Do not
  add moving averages, volume bars, AI markers, or decorative comparison lines.

## Interaction

- Primary action uses a muted champagne surface with dark text.
- Hover changes background or border; never shifts layout.
- Focus uses a 3px translucent charcoal ring.
- Loading states explain the current research stage.

## Responsive behavior

- Below 900px, the left rail becomes a drawer.
- At 760px, split panels stack; compact data rows reflow instead of relying on
  horizontal scrolling.
- At 480px, preserve 16px page gutters and 44px controls.
